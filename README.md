# The Meeting About Meetings

A tiny Node/TypeScript program for the make.fun bounty "One-Line Office Joke: 24-Hour Sprint". It writes one office joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> My calendar invited me to a meeting about meetings, and the only agenda item was finding time to schedule the follow-up about the first meeting.

Run it with: `node main.ts`
